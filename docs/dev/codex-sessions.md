## Not measured and unresolved

- Queue acceptance, receipt, turn start, and reply remain unmeasured. `codex queue --help` proves syntax only. Recipient
  states, target forms, and `--resume` behavior were not exercised.
- Queue behavior for unavailable targets, ambiguous names, failed identity reads, and resume failures remains
  unmeasured. Complete discovery, pagination, and limits remain unmeasured.
- Scheduled-job firing remains unmeasured. Create, list, and delete interfaces were not found in the examined
  ClientRequest schema and native team tool list. This does not prove absence elsewhere.
- The task subagent prompt body was not supplied with the fact-test report.
- A pushed report after a background command ends remains unmeasured. Only polling was observed.
- Persistent notes were not tested because the memory rule bars a write test. `/session-review` was not run because the
  task-subagent limit bars it due to its ability to delete memory notes. The available skill catalog listed
  `simple-english`. The native tool-name inventory `ALL_TOOLS.filter(x => /skill/i.test(x.name))` returned an empty list
  on 2026-11-05; its tool version was not exposed. This scoped observation does not prove absent skill support
  everywhere. The task subagent loaded `simple-english` from its `SKILL.md` as instructions. No native `Skill` call ran.
- Herdr interactive Codex start was rejected after one test tab was approved and closed. The test tab was `wT:t5` and
  the test pane was `wT:p5`. No test-session UUID exists because no test agent started. Correct inherited context, stale
  inherited context, failed read, no match, and several matches did not run.
- Session naming remains unresolved at Herdr start, native rename, same-UUID read-back, exact-name lookup, automatic
  Herdr binding, and replacement binding. Expected `planner-<slug>` and `orchestrator-<slug>` names remain unmeasured.
  No timing stage was measured.
- Interactive model, effort, and first-prompt behavior remain unmeasured at launch and, where applicable, at the first
  model call. The effort limit includes `max`.
- Effective interactive permission mode and approval reviewer, policy, and sandbox remain unmeasured. Help text does not
  establish these results.
- Interactive use of user rules and context-use status remain unmeasured. The candidate command
  `codex -C /tmp/tasker-664-measures [PROMPT]` was not run; the Herdr test-agent start was rejected.
- Automatic pane and workspace selection remains unresolved until a measured current UUID joins to exactly one pane and
  its current workspace. The inherited `wT` context is not such a match.
